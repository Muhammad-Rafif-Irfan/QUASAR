# QUASAR Frontend

Initial frontend scaffold for the QUASAR logistics operations dashboard.

This first step contains only a minimal React + TypeScript + Vite page. The dashboard wireframe has not been implemented yet, and there is no routing, API integration, Tailwind CSS, Folium integration, or advanced component work.

## Requirements

- Node.js 20 or newer
- npm

## Install dependencies

From this folder:

```bash
npm install
```

## Run the development server

```bash
npm run dev
```

Open the URL printed by Vite, normally:

```text
http://localhost:5173/
```

## Production build

```bash
npm run build
```
